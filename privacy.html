プライバシーポリシー

対象: yt-shorts-bot（「知らんかった研究所」の動画投稿ツール）／最終更新日: 2026年10月11日

1. このツールについて

yt-shorts-bot（以下「本ツール」）は、運営者が自分の YouTube チャンネルに自作の動画を投稿するためだけに使う個人用ツールです。 一般の利用者に提供するサービスではなく、運営者以外の Google アカウントでログインすることはありません。

2. 取得する情報

本ツールは、Google の OAuth 認証により、運営者自身の Google アカウントについて https://www.googleapis.com/auth/youtube.upload（動画のアップロード）の権限のみを取得します。 運営者以外の個人情報、チャンネル登録者・視聴者の情報、コメントなどは取得しません。

3. 情報の使い方

取得した権限は、運営者が作成した動画を運営者自身の YouTube チャンネルにアップロードする目的だけに使います。 広告、分析、第三者への提供、販売には使いません。

4. 保存と管理

認証に必要なトークンは、運営者だけがアクセスできる GitHub の暗号化されたシークレットに保存し、動画のアップロード時にのみ使います。 ほかの場所には保存せず、第三者と共有しません。

5. 第三者への提供

本ツールが Google API から受け取った情報を第三者に提供・販売・開示することはありません。

6. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に従います。

7. YouTube API サービスの利用

本ツールは YouTube API サービスを利用しています。本ツールを利用することで、 YouTube 利用規約に同意したものとみなされます。 Google によるデータの取り扱いについては Google プライバシー ポリシーをご覧ください。

8. アクセス権の取り消し

本ツールに与えたアクセス権は、 Google アカウントのサードパーティ アクセス設定からいつでも取り消せます。 取り消すと、本ツールは保存していたトークンを使えなくなります。

9. 変更

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。

English summary

yt-shorts-bot is a personal tool used only by its owner. It requests only the youtube.upload scope for the owner's own Google account, and uses it solely to upload the owner's videos to the owner's own YouTube channel. Tokens are stored only in the owner's encrypted GitHub secrets and are never shared, sold, or used for any other purpose. yt-shorts-bot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using this tool you agree to the YouTube Terms of Service; see also the Google Privacy Policy. Access can be revoked at any time at Google Account permissions. Contact: kikkikukkuku@gmail.com
