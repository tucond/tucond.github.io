食べ物・ものづくり・IT技術の歴史や豆知識を、30秒前後のYouTubeショートで届けるチャンネルです。

yt-shorts-bot について

yt-shorts-bot は、このチャンネルの運営者が自分のチャンネルに動画を投稿するためだけに使う個人用ツールです。 台本の作成・事実確認・動画の編集を自動で行い、YouTube Data API を使って運営者自身の YouTube チャンネルにアップロードします。 第三者のアカウントやデータを扱うことはありません。

yt-shorts-bot is a personal tool used only by the owner of this channel to upload their own videos to their own YouTube channel via the YouTube Data API. It does not access any other user's account or data.
